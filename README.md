# 🧩 Pokémon API Fetcher with React + Vite

A lightweight and responsive web app built with **React** and **Vite.js** to fetch and display Pokémon data using the [PokéAPI](https://pokeapi.co/).

## 🚀 Features

- ⚡️ Fast development with Vite
- 📡 Fetches data from the PokéAPI
- 🔍 Search or list Pokémon
- 📱 Responsive and modern UI
- 🧼 Clean and simple codebase

## 🛠️ Tech Stack

- React
- Vite.js
- Fetch API
- CSS Modules

## 📦 Installation

```bash
git clone https://github.com/omjaisatya/PokeApi.git
cd PokeApi
npm install
npm run dev
```
